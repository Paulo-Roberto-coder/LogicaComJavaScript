# Lógica de Programação com JavaScript

Exercícios que desenvolvi durante meu curso de lógica de programação em JavaScript, organizados por assunto. Cada arquivo tem comentários explicando o que o código faz.

## 📂 Conteúdo

| Pasta | Assunto |
|---|---|
| `inicio` | Variáveis e troca de valores |
| `operadores` | Operadores aritméticos |
| `sinais` | Operadores de atribuição composta (`+=`, `*=`...) |
| `operdores logicos` | Operadores lógicos (`&&`, `\|\|`, `!`, `??`) e ternário |
| `if e else` | Estruturas condicionais |
| `switch_` | Estrutura `switch` |
| `while` | Laços `while` e `do...while` |
| `for` | Laços `for`, `for...in`, `for...of` e loops aninhados |
| `array` | Arrays e métodos (`concat`, `join`, `forEach`) |
| `funcao` | Funções, funções como parâmetro, retorno de funções e currying |
| `objeto` | Objetos, métodos, `this`, `prototype` e classes |
| `desafios` | Desafios práticos juntando os assuntos |

## ▶️ Como executar

É preciso ter o [Node.js](https://nodejs.org) instalado. No terminal, dentro da pasta do projeto:

```bash
node for/for3.js
```

Troque o caminho pelo arquivo que quiser rodar.
